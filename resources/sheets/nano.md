# nano

Simple modeless terminal editor. `^` denotes `Ctrl`, `M-` denotes `Alt` (or `Esc` then key).

## Files

::: entries
Ctrl+O                >>  Write (save) file
Ctrl+R                >>  Read (insert) file
Ctrl+X                >>  Exit (prompts to save)
Ctrl+S                >>  Save without prompt (newer versions)
:::

## Navigation

::: entries
Ctrl+A                >>  Start of line
Ctrl+E                >>  End of line
Ctrl+Y                >>  Page up
Ctrl+V                >>  Page down
Ctrl+_                >>  Go to line number
Alt+\\                >>  Go to first line
Alt+/                 >>  Go to last line
Ctrl+Space            >>  Next word
Alt+Space             >>  Previous word
:::

## Editing

::: entries
Ctrl+K                >>  Cut current line
Alt+6                 >>  Copy current line
Ctrl+U                >>  Paste
Alt+U                 >>  Undo
Alt+E                 >>  Redo
Ctrl+J                >>  Justify paragraph
Alt+J                 >>  Justify entire file
Alt+3                 >>  Comment / uncomment line
:::

## Search

::: entries
Ctrl+W                >>  Search forward
Alt+W                 >>  Repeat last search
Ctrl+\\                >>  Replace
Alt+R                 >>  Replace (alt binding)
:::

## Misc

::: entries
Ctrl+G                >>  Display help
Ctrl+C                >>  Show cursor position
Alt+#                 >>  Toggle line numbers
Alt+S                 >>  Toggle soft wrap
:::
